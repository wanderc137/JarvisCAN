# rec/ — video explicativo

Este directorio contiene el video asciinema de **JarvisCAN · telemetría del auto, sin nube** y el reproductor
que se usa en la página del proyecto.

- `JarvisCAN.cast`: grabación original (asciicast v2).
- `JarvisCAN.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:13. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
